## Project idea

MVPH is an online marketplace for phones, laptops, accessories and gadgets where customers compare products, filter by what they need, and buy with a simple checkout.

## 5-stage tool map

| # | Stage | Tool | Why |
|---|-------|------|-----|
| 1 | Structure | Relume | Generates a sitemap and wireframe sections from a short prompt, so all pages (Home, Category, Product, Compare, Cart) are planned before any design starts. |
| 2 | Concept | Claude + Figma | Claude drafts copy, filter logic and layout ideas. Figma turns them into the visual direction: colors, typography, product-card and filter styles. |
| 3 | Prototype | Figma Make | Converts the concept into a clickable prototype so the browse, filter and checkout flow can be tested before building. |
| 4 | Publish | Vercel | Puts the project on a live link that can be shared to collect feedback. |
| 5 | Full app | Lovable + Supabase | Adds real functionality behind the design: product catalog with filtering, cart, user accounts and order handling. |
